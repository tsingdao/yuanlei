CSS 变量 Custom Properties

用 袁磊 的方式学习 CSS 自定义属性 — 定义一次，全局复用，轻松实现主题切换。

常用 CSS 变量

--yuan_primary

主色调，用于标题、导航栏和按钮等核心元素。

--yuan_primary: #2c3e50;

--yuan_accent

强调色，用于高亮、悬停状态和重点标注。

--yuan_accent: #e74c3c;

--yuan_bg

页面背景色，营造整体视觉基调。

--yuan_bg: #ecf0f1;

--yuan_card

卡片背景色，用于内容区块和面板。

--yuan_card: #ffffff;

--yuan_muted

辅助文字色，用于次要说明和描述文本。

--yuan_muted: #7f8c8d;

--yuan_radius

圆角大小，统一控制元素的圆角风格。

--yuan_radius: 12px;

--yuan_transition

过渡时间，控制状态切换的动画速度。

--yuan_transition: .3s ease;

--yuan_shadow

阴影参数，为卡片和面板添加层次感。

--yuan_shadow: 0 4px 24px rgba(...);

点击切换主题色

下方预览框的颜色由 CSS 变量控制，切换变量即可改变外观。

袁磊的 CSS 变量演示

核心代码

/* 在 :root 中定义变量 */
:root {
    --yuan_primary: #2c3e50;
    --yuan_accent: #e74c3c;
    --yuan_bg: #ecf0f1;
}

/* 使用 var() 引用变量 */
.yuan_card {
    background: var(--yuan_card);
    border-radius: var(--yuan_radius);
    box-shadow: var(--yuan_shadow);
}
