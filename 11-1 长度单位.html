CSS · 长度单位

Web 前端长度单位

绝对与相对 从像素到视口单位，理解 CSS 中每一个长度值的含义与适用场景。

ABSOLUTE UNITS / 绝对单位

固定长度，不随环境变化

px

像素，最常用的绝对单位。1px 等于屏幕上的一个物理像素点。

font-size: 16px; margin: 20px;

pt

磅（Point），印刷单位。1pt = 1/72 英寸，常用于打印样式。

font-size: 12pt; /* ≈ 16px */

in / cm / mm

英寸、厘米、毫米。物理长度单位，适合打印样式表。

width: 8.5in; height: 21cm;

pc

派卡（Pica），印刷单位。1pc = 12pt = 1/6 英寸。

margin: 1pc; /* ≈ 20px */

q

四分之一毫米（Quarter-millimeter）。1q = 1/4mm，较新单位。

font-size: 4q; /* = 1mm */

RELATIVE UNITS / 相对单位

相对于父元素或视口的长度

em

相对于父元素的 font-size。若父元素为 16px，则 2em = 32px。

padding: 1.5em; /* 相对于父级字号 */

rem

相对于根元素（html）的 font-size，避免嵌套影响，响应式首选。

font-size: 1.25rem; /* 相对于 html 字号 */

vw / vh

视口宽度/高度的百分比。1vw = 视口宽度的 1%，适合全屏布局。

width: 100vw; height: 100vh;

vmin / vmax

视口宽高中较小/较大的那个的百分比，适配横竖屏。

font-size: 5vmin; /* 适配屏幕方向 */

%

相对于父元素对应属性的百分比，广泛用于布局和字体。

width: 50%; font-size: 87.5%;

ch / ex

ch 相对于 "0" 字符宽度；ex 相对于小写 "x" 的高度。

max-width: 60ch; /* 控制文本行宽 */

CALC() / 计算函数

混合不同单位进行计算

示例 1：侧边栏布局

.container {
  display: flex;
}
.sidebar {
  width: 200px;
}
.main {
  width: calc(100% - 200px);
}

示例 2：响应式字体

h1 {
  font-size: calc(1.5rem + 2vw);
  /* 在 1.5rem ~ 3.5rem 之间平滑缩放 */
}

示例 3：居中容器

.box {
  width: min(100% - 40px, 800px);
  margin: 0 auto;
}

示例 4：网格间距

.grid {
  display: grid;
  grid-template-columns: repeat(
    3,
    calc((100% - 48px) / 3)
  );
  gap: 24px;
}
