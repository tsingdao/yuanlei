长度从 1px，到一整屏。

px、in、em、rem、vw、ch…… 网页里每一个尺寸都有「参照物」。这一页把所有长度单位放在同一张蓝图上量一量。

标尺刻度 —— 每一小格 = 10px · 每一大格 = 50px

01

绝对单位

ABSOLUTE UNITS

不依赖任何参照物的「硬尺寸」。屏幕上约定 1in = 96px（即 96 DPI），其余物理单位都由它推算。注意小尺寸单位在屏幕上有多微小。

相对单位 —— em 与 rem

FONT-RELATIVE

em 相对「当前元素」的字号，嵌套时会逐层复合；rem 永远相对根元素 <html> 的字号，是全局统一的标尺。拖动滑块改变两列的基准字号，观察哪一列纹丝不动。

相对单位 —— 视口单位

VIEWPORT UNITS

vw / vh 相对视口宽 / 高的 1%；vmin / vmax 取视口较小 / 较大边的 1%。窗口缩放时它们实时变化 —— 下面的读数由脚本实时刷新。

用 vmin 可以轻松画出「永远不超出屏幕」的正方形：竖屏时它跟着宽度走，横屏时跟着高度走。

04

相对单位 —— 字符单位

CHARACTER UNITS

ch 是当前字体中字符「0」的宽度，常用来限制输入框宽度；ex 是小写字母「x」的高度，与字体的 x-height 挂钩。等宽字体下 20ch 恰好装下 20 个字符。

06

实战提示

FIELD NOTES

几条写 CSS 时真正会用到的经验。

NOTE 01

字号用 rem，布局用 % 或 flex

rem 让用户浏览器字号缩放（无障碍）全局生效，同时不产生 em 的复合陷阱。

NOTE 02

流体排版：clamp + vw

font-size: clamp(1rem, 1.5vw, 1.5rem) —— 随视口缩放，但永不越界，无需媒体查询。

NOTE 03

width: 100vw 的坑

100vw 包含滚动条宽度，竖向滚动条出现时可能产生横向溢出。布局宽度优先写 100%。

NOTE 04

更细的「发丝线」

高 DPI 屏幕上 1px 边框可能偏粗，可用 transform: scaleY(0.5) 画出视觉 0.5px 的线。
