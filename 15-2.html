一、条件结构

根据条件的真假选择执行不同的代码分支。

1. if…else if…else：成绩等级

if (yl_score >= 90) { yl_grade = "优秀"; }
else if (yl_score >= 80) { yl_grade = "良好"; }
else if (yl_score >= 60) { yl_grade = "及格"; }
else { yl_grade = "不及格"; }

  case 1: yl_name = "星期一"; break;

  …
  default: yl_name = "输入无效";
}

二、循环结构

让一段代码重复执行，直到条件不满足为止。

1. for 循环：1~100 求和

for (var yl_i = 1; yl_i <= 100; yl_i++) {
  yl_sum += yl_i;
}

2. while 循环：1~50 中的偶数

while (yl_n <= 50) {
  yl_evens.push(yl_n);
  yl_n += 2;
}

3. do…while 循环：5 秒倒计时

do {
  yl_out += yl_count + " ";
  yl_count--;
} while (yl_count > 0);

4. 嵌套 for 循环：九九乘法表

for (var yl_i = 1; yl_i <= 9; yl_i++)
  for (var yl_j = 1; yl_j <= yl_i; yl_j++)
    yl_html += yl_j + "×" + yl_i + "=" + yl_i * yl_j;
